# Rhythm Wave Lab 2

**音の強弱の変化を、周波数解析して観察するWindows用アプリです。**

音声から瞬間振幅を取り出し、その時間変化をフーリエ解析します。ここで扱う周波数は、振幅がどのくらいの速さで変化しているかを表します。例えば、1秒間に2回繰り返す変化は2 Hz、BPM相当の表示では120になります。

音声を再生しながら、強弱の変化に含まれる周期成分や、特定の成分の振幅・位相を観察できます。テンポ・拍子・音符の長さを指定し、それに対応する周波数とハーモニクスを表示することもできます。

## ダウンロード・起動

**[Releasesからダウンロード](https://github.com/uriop-dogg/fourier_music/releases)**

1. Releasesの **Assets** から、`RhythmWaveLab-…-Windows-x64-portable.zip` をダウンロードします。
2. ZIPをすべて展開します。
3. 展開したフォルダーの `RhythmWaveLab2.exe` を起動します。

GitHubが自動生成する `Source code (zip)` ではなく、上記のポータブル版ZIPを選んでください。

- 対応環境：Windows 10 / 11、64ビット（x64）
- PythonやFFmpegなどの追加インストールは不要です。
- `_internal` フォルダーはexeと一緒に保管してください。exeだけを移動すると起動できません。
- 音声の解析はPC内で行い、アプリから音声を外部へ送信することはありません。

## 表示できるもの

| 表示対象 | 内容 |
| --- | --- |
| 音声波形と瞬間振幅 | 青い音声波形と白い瞬間振幅を重ねて表示します。 |
| 瞬間振幅の全周波数 | 強弱の変化に含まれる周波数成分を表示します。現在位置のSTFTと、音声全体のFFTを切り替えられます。 |
| 固定周波数表示 | 指定した周波数成分の時間波形、または位相を表示します。周波数はHz・BPM相当で指定できます。 |
| 基本周波数の指定 － ハーモニクス表示 | 指定した基本周波数の整数倍の成分を棒グラフで表示します。周期の長さに対応する音符も表示します。 |

複素数の成分は、絶対値・絶対値（位相色）・実部・虚部に切り替えられます。単体・2画面・4画面のレイアウトを選び、各画面に表示対象を配置できます。

## まず試すには

起動すると、サンプル音源 `rhythms2.wav` を自動で読み込んで解析します。解析が終わったら再生し、グラフの変化を見てみてください。

「ファイル → サンプル音源」から、次の2曲を選べます。

| サンプル | 読み込み時に設定されるテンポ |
| --- | --- |
| `rhythms2.wav` | 110 BPM |
| `stone.wav` | 128 BPM |

テンポは読み込み後に手動で変更できます。自分の音声は「音声を開く」から読み込めます。WAV・FLAC・MP3・M4A・OGG・AIFFの読み込みを確認しています。

## 設定と読み方

「基本周波数/ハーモニクス」タブで、テンポ・拍子・基本周波数に対応する音符・ハーモニクス上限を指定します。テンポは四分音符基準のBPMです。初期設定は110 BPM、4/4拍子、基本周期は1小節、ハーモニクス上限は32です。

「フーリエ設定」タブでは、STFTの窓長や時間刻みなどを変更できます。設定タブでの変更は「解析・条件を適用」で反映します。

- **窓長**を長くすると近い周波数を区別しやすくなりますが、時間方向の変化は平均化されます。
- **時間刻み**を長くすると計算する時点が減り、計算量を抑えられます。
- **BPM相当**は周波数を60倍した表示です。楽曲のテンポを自動検出した値ではありません。
- **ハーモニクス下の音符**は、その成分の周期の長さを示します。実際に演奏された音符を判定した結果ではありません。

周期的な振幅変化には複数のハーモニクスが現れます。また、音の重なりや干渉による振幅変動も解析に含まれます。音声を聴きながら、各成分がどのような変化に対応するかを観察できます。

## 保存・書き出し

- **プロジェクト（`.irhythm`）**：音声・解析結果・設定を保存し、後から開けます。
- **CSV / NPZ**：解析データを書き出せます。複素数の実部・虚部・絶対値・位相などを含みます。
- **SVG**：グラフを書き出せます。

## 言語・詳しい説明

日本語・Englishに対応しています。日本語画面では「LANGUAGE」、英語画面では「言語」メニューから切り替えられます。

詳しい操作方法や計算式は、アプリの「使い方と数式」から確認できます。配布ZIPには日本語の `README.html` と英語の `README.en.html` も同梱しています。
